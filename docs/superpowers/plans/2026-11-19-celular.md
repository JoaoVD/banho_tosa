# Uso pelo celular — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O sistema fica bom de usar no celular (tosador e recepção no dia a dia) sem mudar nada no PC.

**Architecture:** Mesmo código, adaptado por CSS em `@media (max-width: 899px)` (navegação) e
`@media (max-width: 699px)` (telas). Onde a tela muda de forma, o componente renderiza as duas formas
ou marca o estado em `data-*` e o CSS escolhe — **nunca** `matchMedia` no render (evita diferença entre
servidor e cliente). Nova barra de abas + folha "Mais" substituem a barra lateral no celular.

**Tech Stack:** Next.js 15 App Router, CSS (tokens.css + CSS modules), Radix Dialog, Playwright 1.63 (chromium).

**Spec:** `docs/superpowers/specs/2026-11-19-celular-design.md`

## Global Constraints
- PC (≥ 900 px) idêntico: todos os e2e de desktop existentes passam **sem alteração**.
- Navegação de celular abaixo de **900 px**; ajustes de tela abaixo de **700 px**.
- Abas, nesta ordem: **Hoje · Agenda · Mensagens · Pets · Mais**. "Mais" contém Pacotes e pontos, Caixa, Configurações (só dona), loja/papel e **Sair**.
- Alvos de toque ≥ **44 px**; campos com fonte ≥ **16 px** no celular.
- Página nunca rola para o lado no celular (`scrollWidth <= innerWidth`); tabelas largas rolam dentro do cartão.
- Respeitar `env(safe-area-inset-*)` na barra de abas, no cabeçalho e nas folhas.
- Modo claro, tokens existentes; sem cores novas fora de `tokens.css`.
- Importar, Boas-vindas e Configurações: só sem rolagem lateral; sem redesenho.

## Review Focus
1. **Teclado aberto no celular** (responder mensagem, buscar): o campo em foco não pode ficar coberto pela barra de abas — a barra some quando um campo de texto tem foco (`body:has(input:focus, textarea:focus)`). Teste na Task 6.
2. **Girar para paisagem / tablet entre 700 e 899 px**: barra de abas presente e telas no layout de PC sem estouro. Teste de largura na Task 1 roda também em 820 px.
3. **Folha aberta + barra de abas**: a folha fica por cima da barra (z-index), e o botão de ação da folha visível sem rolar a página. Teste na Task 2.
4. **Etapa vazia no Quadro**: o seletor começa na primeira etapa com pets; se todas vazias, "Chegando" com o estado vazio. Teste na Task 3.
5. **Busca global no celular**: tocar 🔍 abre o campo, Enter leva a `/pets?q=` mostrando a lista (não a ficha). Teste na Task 5.
